# Tom, Bert, and William

Pay {1} and sacrifice another creature you control as costs. Neither the source nor an opponent's creature is a valid sacrifice. If either cost is unavailable, fail before sacrificing or spending mana. This ability does not tap the source and remains usable after it returns as an artifact.

Capture the sacrificed creature's power when paying the cost, including counters and continuous effects. Each activation must retain its own value even when several activations of the same ability are pending. At resolution draw that many cards, then discard one if a card is available. Zero or negative power means no cards drawn but does not remove the discard instruction.

The death trigger applies only if this permanent was a creature immediately before it died. Return the same graveyard object under its owner's control; if it left the graveyard before resolution, do not return a later incarnation. A token does not return.

Apply the artifact-only type change as the permanent returns, before entry triggers and state-based actions. It remains legendary, retains its abilities and mana cost, and loses creature subtypes. Continuous-effect recalculation must preserve this change for that battlefield stint. If it leaves and is cast again, restore the printed creature characteristics. An artifact dying without being a creature must not trigger another return.
