# The Notary Hobbits

The original permanent's own entry triggers its ability. Resolve that trigger by creating exactly two token copies, with the not-legendary exception already present when they enter. A token copy does not trigger this ability again. Token multiplication effects still apply to token creation.

Use the engine's copy/token paths so each token has independent identity, counters, tapped state and ability bindings. Do not copy counters or temporary power/toughness modifications from the original. Removing legendary from a token must not remove it from the original.

The activated ability is a mana ability: it produces mana immediately without using the stack and may be activated during mana payment. Represent it using the canonical ManaAbility descriptor. Count Halflings you control at resolution, including this permanent and both copies, regardless of whether they are tapped. Do not count an opponent's Halflings or require that a Halfling also be a creature.

The tap cost respects tapped state and summoning sickness while the source is a creature. Every copy has its own tap cost and produces mana for its own controller. Successful activation of a creature's mana ability can trigger abilities such as Elrond's.
