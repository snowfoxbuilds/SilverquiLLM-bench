# Directory Summary — `benchmarks/sos/`

## Purpose

Benchmark data and artifacts for the **Shadows over Sonnenthal (SOS)** set — 368 cards fetched from Scryfall. Contains raw card data, classified tiers, per-card specs, comprehensive rules, prototype card selections, and result output directories.

## Key Files

| Path | Responsibility |
|------|---------------|
| `__init__.py` | Package init for SOS benchmark set. |
| `fetch_data.py` | SOS data fetcher — downloads from Scryfall, normalizes card fields, logs stats. Has CLI mode (`python -m benchmarks.sos.fetch_data`). |
| `prototype_cards.json` | 5 prototype cards (one per complexity tier) selected by scoring-based preferences. |
| `prototype_gaps.md` | Engine gap analysis — documents which engine features are missing for prototype cards (e.g., Converge mana tracking). |

## Subdirectories

| Directory | Contents |
|-----------|----------|
| `data/` | Raw and processed data files. |
| `cards/` | Per-card directories (`1/` through `368/`), each containing `card_spec.json`. |
| `results/` | Benchmark run outputs (initially empty with `.gitkeep`). |

## Data Files (`data/`)

| File | Responsibility |
|------|---------------|
| `sos.json` | Normalized SOS card data — 368 cards fetched from Scryfall with standardized fields. |
| `sos_classified.json` | Classification output — each card annotated with complexity tier (trivial/simple/medium/complex/advanced). |
| `comprehensive_rules.txt` | Cached MTG comprehensive rules text. |
| `rules_overview.md` | Compact MTG rules overview (~573 tokens) suitable for agent context windows. |

## Per-Card Specs (`cards/{n}/card_spec.json`)

Each card gets a numbered directory containing `card_spec.json` with:
- Card oracle data (name, mana cost, type line, oracle text, power/toughness, keywords)
- Complexity tier from the classifier
- Used as agent context during benchmark runs

## Conventions

- Card numbering (`1/` through `368/`) matches collector number order from Scryfall.
- Data files in `data/` are regenerated by running the fetch/classify/rules scripts; they are checked in for reproducibility.
- Results in `results/` are per-run isolated directories generated by `benchmark/results.py`.
