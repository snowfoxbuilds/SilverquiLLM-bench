# FRA hard implementation task

Implement the ten selected cards listed in the card specs under cards/fra/ and cards/hob/. Keep each class in its assigned card_impl.py with its provided name. card_spec.json contains the complete card specification, including card_faces for cards with multiple components. Implement the whole card.

You may change engine/ freely. Use the Player Query / Player Decision protocol for choices. Your tests belong beside target implementations. Existing engine and FDN tests are read-only. Run `python3 -m pytest` from the workspace root. Consult RULEBOOK.txt for rules and test_utils.md for test APIs.
