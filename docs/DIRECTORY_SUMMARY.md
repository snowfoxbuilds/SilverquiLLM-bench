# Directory Summary — `docs/`

## Purpose

Documentation and specification files for the SilverquiLLM-bench project. Contains the design specs under `specs/` and the decision records under `adr/` (both maintained in-repo), plus auto-generated reference docs for agents.

## Key Files

| Path | Responsibility |
|------|---------------|
| `specs/` | Design specifications, one page per topic. See the Specs index in the repo-root [AGENTS.md](../AGENTS.md). |
| `adr/` | Architecture Decision Records, one decision per file. Each spec's **Relevant ADRs** appendix links the decisions behind it. |
| `engine_api.md` | **Auto-generated** engine API reference — produced by `silverquillm/docs_gen.py` via AST extraction. Used as agent context. |
| `HELP.md` | Help and troubleshooting guide. |

## Dependencies

- `engine_api.md` is regenerated by `silverquillm/docs_gen.py`, which reads the engine source via AST.
- The `specs/` index and project-wide conventions live in the repo-root `AGENTS.md`; the domain glossary lives in the repo-root `CONTEXT.md`.
